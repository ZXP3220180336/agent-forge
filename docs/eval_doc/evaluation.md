## 定位与目标

Agent 系统质量的**度量体系**——保证功能正确、行为可靠、成本可控。这是工业级 Agent
与功能演示的分水岭：**评测集闭环 + 回归评测**（代码变更后自动回归，防质量回退）。

**目标**：

1. **质量可度量**：任务成功率 / 工具调用准确率 / 延迟 / 成本等指标有明确基线
2. **回归可重复**：评测集与评测流程固定，代码变更后可对比前后质量
3. **成本可追踪**：评测消耗的 token / 成本纳入成本治理

# 组件级子文档设计规范

适用于 `docs/<layer>_doc/<module>_doc/` 下的组件说明，面向模块内部维护者及合法协作方。共用的事实判定、状态、配置、示例、格式和验证规则见[工程文档维护规范](README.md)；本文件只规定组件说明的粒度与内容。

## 定位与协作契约

组件说明回答“内部如何协作、哪些行为不能破坏、为什么采用当前设计”。它不重复模块的公开 Facade 方法表，也不要求每个源码文件都有独立长文档。按职责和维护需要组织，一个组件可以由多个文件共同实现。

组件的**内部协作契约**包括被同模块调用方依赖的方法、数据、状态迁移、资源所有权、异常传播和调用次序，即使它们不属于模块公开 API，也可以在此集中说明。内部辅助函数仅在影响该协作契约或关键不变量时解释；不要机械列出所有私有方法。这里的“内部接口”不授权其他层绕过模块 Facade。

契约参考与设计解释分节：接口、边界用于维护和调用；机制用于解释当前行为；已接受方案的完整备选与取舍链接 ADR，问题经过链接 Issue。

## 选择文档粒度

| 组件特征 | 建议内容 |
| --- | --- |
| 行为稳定、状态少、协作契约直接 | 模板 A：轻量契约参考、边界和少量示例 |
| 存在状态机、重试、并发、资源生命周期或复杂失败语义 | 模板 B：增加机制、状态/执行流程、资源责任及针对性验证 |

方法数和行数只能辅助感知复杂度，不决定必须采用哪个模板。短组件也可能有高风险生命周期，长文件也不必按每个方法重复解释。依据受影响契约选择章节，顺序可调整；不为达到约 80 行或固定章序删掉必要语义。

## 模板 A：轻量组件

```text
# <组件名>说明
> 对应代码：<文件或职责范围>
> 文档定位：内部协作契约与维护说明
> 更新日期：<本次编辑日期>
> 状态与映射：<指向 docs/ALIGNMENT.md 对应条目>

## 定位与职责
几句话说明职责、合法协作方与边界。

## 内部协作契约
| 符号/数据 | 输入与默认值 | 输出/异常 | 协作方责任 |
说明必要公式、状态或所有权语义；不重复模块公开契约表。

## 行为边界
| 触发场景 | 行为 | 约束或验证入口 |
按实际契约选择缺失、非法、边界值和失败形态。

## 使用示例
一两段内部协作的最小示例；标明不是模块外部推荐入口。

## 设计依据
必要的机制解释；既有决策链接 ADR。

## 验证入口
测试文件/关键场景及其可观察行为；验证状态链接 ALIGNMENT。

## 相关文档
模块公开契约、协作组件及相关配置参考。
```

## 模板 B：复杂组件

在模板 A 上按实际风险扩展。以下是建议结构，不是强制章序：

```text
# <组件名>设计说明
> 对应代码 / 文档定位 / 更新日期 / 状态与映射链接

## 目录
较长文档提供主要章节导航。

## 设计目标与边界
组件解决什么问题，哪些责任在别处。

## 内部协作契约
方法/数据/返回/异常/调用方责任，集中说明关键语义。

## 核心概念与机制
定义必要概念，说明算法、预算、状态或资源协议。

## 结构与协作
调用链/依赖关系、组件职责；图按共用格式规则选择。

## 状态与执行流程
正常路径、失败路径和恢复入口；复杂时补状态表。
涉及资源时交代取得、移交、结算、释放与异常责任。

## 关键实现说明
仅解释维护者必须理解的非显然约束，短示意指向源码。
不完整复制生产实现，不重复上节流程。

## 行为边界
按组件实际风险列取消、期限、重入、并发、部分结果等。

## 配置关联
说明配置对机制的影响；键、默认值及约束链接配置参考。

## 验证入口
测试文件/关键场景 → 可观察行为；状态链接 ALIGNMENT。

## 设计决策与问题记录
ADR / Issue 的标题、简短关联说明和链接，不复述历史全文。

## 相关文档
模块公开契约、协作组件及必要的全局协议。
```

## 本类型的核对重点

1. 内部调用方是否能找到输入、返回、异常、状态和资源责任；组件协作接口是否被误写成模块外部 Facade。
2. 状态和流程是否覆盖真实失败出口，示意片段是否与已接受契约一致；发现实现冲突时是否留下明确差异，而非照抄一方。
3. 测试入口是否对应实际断言，是否把仅执行到某文件的“间接覆盖”夸大成行为验证；有意义的场景优先于写死测试数量。
4. 新建或移动说明是否更新模块导航与 ALIGNMENT 映射；父文档只保留入口，不复制组件说明。

模块公开调用面见[模块规范](module_doc.md)，层级地图见[层级 README 规范](layer_readme_doc.md)。维护操作与验证流程统一执行 [README 中的维护入口](README.md#维护与验证入口)。

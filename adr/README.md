## 登记规范

1. **命名**：`<日期>-<短横线描述>.md`（`YYYY-MM-DD`，决策确立日）。
2. **模板**：标题 + 元信息块（状态/决策日期/涉及层级/关联文档）→ `Context`（背景 + 动机 + 备选 + 工业参照）→ `Decision`（编号决策，含取舍）→ `Consequences`（✅ 正面 / ⚠️ 代价 / 📌 升级路径）。
3. **登记**：新建文件后同步更新上方索引表（ID / 标题 / 状态 / 层级 / 日期）。
4. **正文中文**；结构/依赖图代码块指定 `text` 语言。

## 维护原则

- **与 issues/ 分离**：ADR 记「为什么选此方案 + 取舍 + 后果」；issues 记问题「发现 → 修复 → 验证」生命周期。
- **写当前状态不写历史**：决策被替代时改状态徽标 + 链接替代文件，不保留演进叙事。
- **一个决策一个文件**：横切与单层决策分开放（单层决策仍归 `adr/<层>/<模块>/`）。

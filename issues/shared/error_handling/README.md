## 新问题登记规范

1. **命名**：`<日期>-<短横线描述>.md`——日期为问题确立日（`YYYY-MM-DD`），描述为该问题的短 slug
2. **编号（索引 ID）**：SHARED-XXX 递增，仅用于索引表展示；**文件名不含编号**
3. **模板**：元信息块（状态/优先级/来源/涉及模块）→ 问题描述（现象/影响/根因）→ 工业级参照 → 修复方案（含决策取舍）→ 实施记录 → 验证 → 教训沉淀
